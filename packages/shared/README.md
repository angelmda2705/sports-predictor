# packages/shared

Contratos y tipos compartidos entre servicios (esquemas de la API, enums de deportes,
constantes de mercados de predicción). Evita que `apps/web`, `apps/api` y `packages/ml`
diverjan en las definiciones.

> 🚧 Se completa cuando exista el primer contrato de API estable (Fase 1, tras auth y
> catálogo). El contrato se deriva del OpenAPI que genera FastAPI.
